a free tool for Chinese learners: type any Chinese text and get a printable
handwriting practice sheet — with stroke-order animation, pinyin toggle and grid options (田字格 / 米字格).
> ✅ 100% free, no account needed
> ✅ Interface in 11 languages (EN / 中 / 日本語 / 한국어 / Español / Français / Deutsch / العربية / ไทย / Tiếng Việt …)
> ✅ Built-in HSK lists, classical poems and novel word packs
> ✅ Export A4 PDF, print-ready
 Great for teachers assigning homework or learners practising writing.
